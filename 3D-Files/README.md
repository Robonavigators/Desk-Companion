# Desk-Companion — 3D Printable Enclosure

This folder contains the 3D-printable enclosure files for Desk-Companion.

## ⚠️ Important Notice

These 3D models have not been physically tested to verify a perfect fit.

Minor adjustments may be required depending on:

- 3D printer accuracy and tolerances
- OLED display dimensions
- XIAO ESP32 board dimensions
- TTP223 touch sensor placement
- USB-C port clearance
- Battery dimensions

Please verify all measurements before printing.

Feedback, improvements, and corrected 3D models are welcome through GitHub Issues and Pull Requests.
